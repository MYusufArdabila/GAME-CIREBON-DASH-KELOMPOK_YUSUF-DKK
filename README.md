## Deskripsi Project
Cirebon Dash adalah game endless runner berbasis web dengan tema lokal Cirebon. Game menggunakan Canvas 2D dengan visual procedural, SVG, CSS, dan JavaScript.

## Kategori
Game / Endless Runner

## Fitur Utama
- Endless runner 2.5D
- 3 lane
- Character selection
- Character unlock/shop
- Skill karakter
- Coin system
- High score
- Police chase
- Obstacle
- Kereta
- Pause
- Countdown
- Desktop controls
- Mobile swipe controls
- Responsive layout
- Fullscreen
- Music dan sound effect
- Environment bertema Cirebon

## Teknologi
- HTML
- CSS
- JavaScript
- Canvas 2D
- SVG
- Web Audio API
- localStorage
- Browser APIs
