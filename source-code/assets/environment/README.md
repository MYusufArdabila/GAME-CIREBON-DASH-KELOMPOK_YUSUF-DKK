# DOKUMENTASI LINGKUNGAN MAP (CIREBON CITY RUN) — PART 3

Direktori ini dipersiapkan untuk menyimpan dan mengorganisasi aset visual lingkungan game **Cirebon Dash**.

### 1. `background/`
* `skyline-ciremai.png` / `.svg`: Siluet Gunung Ciremai & kabut atmosferik.
* `megamendung-clouds.png` / `.svg`: Formasi awan bermotif batik Mega Mendung dengan variasi layer.
* `distant-city.png` / `.svg`: Siluet menara dan atap limasan tradisional di horizon.

### 2. `buildings/`
* `ruko-cirebon-1.png` / `.svg`: Rumah toko modern dengan kanopi bergaris.
* `warung-makan.png` / `.svg`: Warung kuliner Nasi Jamblang & Empal Gentong.
* `kios-pasar.png` / `.svg`: Kios pasar tradisional Pasar Kanoman.
* `tembok-keraton.png` / `.svg`: Tembok bata merah berundak khas Keraton Kasepuhan.

### 3. `landmarks/`
* `candi-bentar-arch.png` / `.svg`: Gapura monumental Candi Bentar yang melintang di atas jalan.
* `gapura-kuliner.png` / `.svg`: Gapura gerbang sentra kuliner khas Cirebon.

### 4. `props/`
* `lentera-keraton.png` / `.svg`: Lampu jalan antik dengan cahaya kuning hangat.
* `pohon-tropis.png` / `.svg`: Pohon peneduh jalan & palem.
* `tiang-listrik.png` / `.svg`: Tiang listrik dengan kabel melengkung.
* `pot-bunga.png` / `.svg`: Pot tanaman hias trotoar.
* `rambu-lalu-lintas.png` / `.svg`: Rambu petunjuk jalan kota Cirebon.

### 5. `street/`
* `angkot-cirebon.png` / `.svg`: Angkot biru trayek D6 Kasepuhan-Plered.
* `becak-cirebon.png` / `.svg`: Becak kayuh tradisional Cirebon.
* `motor-parkir.png` / `.svg`: Sepeda motor bebek parkir di trotoar.

---
*Catatan Teknis*: Seluruh elemen di atas saat ini dirender secara dinamis melalui sistem prosedural 2.5D di `js/environment.js` sehingga game dapat langsung berjalan tanpa dependensi gambar eksternal dan tetap sangat ringan di browser.
